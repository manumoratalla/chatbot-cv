# Proyectos de Ana

## Gestor de tareas
Ana desarrolló un gestor de tareas web como proyecto personal. Permite crear, completar y borrar tareas, y está hecho con HTML, CSS y JavaScript en el frontend y con Node.js y Express en el backend.

## Tecnologías que utiliza Ana
Ana programa en JavaScript y Python, y trabaja con bases de datos SQL. Usa Git para el control de versiones.
